Fungi Tri

A 3-state take on Fungi. Each cell is empty, state 1 or state 2. The next state depends on the cell itself and on how many of its orthogonal and diagonal neighbors are in each state: 3 × 15 × 15 = 675 cases, so a rule is 675 trits written as 270 hex characters.

These rules were picked by a MoonBit search. Rules are scored from several random starts: a sparse and a dense random soup over the whole grid, and a random patch in an empty grid that has to spread. Rules that die out, freeze, or boil into noise from those starts score low. To get more than one kind of behavior, a second search bins rules by how they behave (how fast cells change, how full the grid is, how clumped the live cells are) and keeps the best of every bin, starting from families like excitable waves, cyclic rock-paper-scissors, two Life-like species, predator and prey, and voting rules. The caption under each tile names its bin.

Each tile here starts from a fresh random soup on a 96 × 96 grid that wraps at the edges, so every visit looks a little different.

Hover a tile to see its scores, and click it to open it full screen. Press Space to pause, R for a new random start, N to cycle the start between random soup, random patch and a symmetric disk, and Esc to return here. Add ?skip=300 to the address to jump ahead, or ?fill=0.2 to change how full the soup is. This page needs WebGPU, which recent Chrome has.
